# Помощник по тренировкам `ai-agent_Starostina`

**ИИ-агент для записи и отслеживания тренировок.**

## Назначение

**Помощник по тренировкам** помогает сохранять планы занятий, записывать результаты и следить за прогрессом.

## Язык программирования

Проект разрабатывается на языке **Python** (версия `3.14`).

## Планируемые возможности

- Добавление плана тренировки на день.
- Запись выполненных упражнений и подходов.
- Просмотр истории тренировок за неделю.
- Подсчет общего количества выполненных упражнений.
## Примеры работы

**Запрос 1.** «Добавь тренировку: жим лежа 3 подхода по 10 раз».
**Результат:** `Тренировка добавлена: жим лежа, 3x10.`

**Запрос 2.** «Покажи мои тренировки за последнюю неделю».
**Результат:** Выводится список тренировок с датами и упражнениями.

## Технологический стек
- **Язык:** Python (версия 3.14)
- **Среда разработки (IDE):** Visual Studio Code
- **Среда выполнения:** терминал
- **Менеджер зависимостей:** `pip` (сторонние библиотеки не используются)
- **Библиотеки:** только стандартная библиотека Python
- **Хранение данных:** в оперативной памяти (список Python)
- **Отладчик:** встроенный в VS Code Python Debugger
- **Линтер:** `Flake8`
- **Форматтер:** `Black`

## Подготовка и запуск
1. Установите Python 3.14.
2. Откройте проект в VS Code.
3. В терминале введите: `python3 main.py`.

## Команды приложения и справка
Для вывода встроенной справки введите команду `help`. Справка содержит перечень команд и их назначение:
- `add <название>` — добавить новую тренировку.
- `list` — показать список всех тренировок.
- `done <id>` — отметить тренировку выполненной по её номеру.
- `help` — вывести эту справку.
- `exit` — штатное завершение программы.

## Проверка качества кода
- **Форматтер Black:** код отформатирован. Для воспроизведения проверки в VS Code нажмите `Shift + Option + F` 
- **Линтер Flake8:** код написан без ошибок. Для воспроизведения проверки откройте вкладку `Problems` в VS Code
